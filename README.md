# juryjuice-media

Images and code for the Jury Juice daily posting bot.

- `BOT.md`: what the daily scheduled task does, step by step.
- `jury-juice-brief.md`: voice, post types and rules (copied from Hookline).
- `state/`: settings (`config.json`), week 1 plan, and the history of every post with its results.
- `render.js` + `renderer/`: draws slides with Hookline's own code and fonts.
- `posts/<date>/`: slide images Buffer pulls from. Cleared after 30 days.
- `fonts/`: Inter, Montserrat and Bebas Neue (SIL Open Font License).
